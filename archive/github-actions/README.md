# 보관된 GitHub Actions 워크플로

Company-Screener 를 **동면 상태**로 두면서 `.github/workflows/` 에서 이리로
옮긴 파일들입니다. **삭제한 것이 아니라 옮긴 것**이라 `git log --follow` 로
각 파일의 이력이 그대로 따라옵니다.

여기 있는 동안에는 GitHub 이 이 파일들을 워크플로로 인식하지 않습니다.
`.github/workflows/` 밖에 있기 때문입니다.

되살리는 법과 각 파일의 방아쇠 목록은 `.github/workflows/README.md` 에
정리해 두었습니다.
